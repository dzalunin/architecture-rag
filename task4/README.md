# Задание 4. Реализация RAG-бота с техниками промптинга

**RAG‑сервис (Retrieval Augmented Generation)** на базе **FastAPI**, **LangChain**, **FAISS** и **Ollama**. Сервис отвечает на вопросы пользователей **строго на основании внутренней базы знаний**, используя векторный поиск и LLM, запущенную локально через Ollama.

## Архитектура

Поток обработки запроса:

1. Пользователь отправляет вопрос в API.
2. Последний запрос извлекается агентом LangChain.
3. Выполняется поиск релевантных документов в FAISS.
4. Найденный контекст подставляется в **динамический RAG‑prompt**.
5. Ответ генерируется LLM (Ollama) с жёсткими инструкциями:
   * только на русском языке;
   * только на основе предоставленного контекста;
   * с указанием источников.

## Стек технологий

* **Python 3.13+**
* **FastAPI** — REST API
* **LangChain** — агент и middleware
* **FAISS** — векторное хранилище
* **Ollama** — локальный LLM сервер
* **Pydantic Settings** — конфигурация

## Структура проекта (ключевые части)

```
app/
├── api/
│   ├── router.py       # HTTP роуты
│   ├── models.py       # DTO
│   └── depts.py        # Dependency FastAPI, которая предоставляет доступ к инициализированному RAG-контейнеру (агент и retriever)
├── rag/
│   ├── agent.py        # Инициализация и жизненный цикл RAG-агента (LangChain-агент с динамическим RAG-prompt’ом)
│   ├── retrieval.py    # FAISS + embedding поиск
│   ├── safety.py       # Защита от вредоносных запросов
│   └── llm.py          # Клиент Ollama
├── lifespan.py         # Lifespan FastAPI
├── logging.py          # Конфигурация логов
├── settings.py         # Конфиг проекта
├── agent.py            # RAG агент LangChain
main.py                 # Точка входа
```

## Конфигурация

Настройки задаются через переменные окружения.

### Основные параметры

```env
LOG_LEVEL=INFO

# Embeddings
EMBEDDING_MODEL=intfloat/multilingual-e5-base
EMBEDDING_MODELS_CACHE_DIR=cache/models
EMBEDDING_BATCH_SIZE=16

# Vectorstore
VECTORSTORE_DIR=index

# Ollama
OLLAMA_MODEL=llama3
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_PULL_TIMEOUT=600

# Retrieval
SEARCH_TOP_K=3

RUN_IN_SAVE_MODE=true
```

## RAG‑агент

Агент инициализируется при старте приложения:

* Загружается FAISS‑индекс
* Проверяется и при необходимости подтягивается модель Ollama
* Создаётся LangChain‑агент с `dynamic_prompt`

### Особенности prompt'а

* Few‑shot примеры
* Жёсткий формат ответа:

  1. Краткие шаги (до 3)
  2. Итоговый ответ
  3. Источники
* Запрет на галлюцинации
* Ответ **«Я не знаю»**, если контекст пуст

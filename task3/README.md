# Задание 3. Создание векторного индекса базы знаний

## Модель эмбеддингов: `intfloat/multilingual-e5-base`

*  **Официальная страница на Hugging Face:** [https://huggingface.co/intfloat/multilingual-e5-base](https://huggingface.co/intfloat/multilingual-e5-base)
*  **Выходная размерность:** **768**
*  **Обязательный префикс для текстов:**
    Модель обучена с использованием инструкций. Для получения качественных эмбеддингов **необходимо добавлять к своим текстам специальные префиксы**.
    *   Для **документов** (текстов, которые индексируете): `passage: `
    *   Для **запросов** (вопросов пользователя): `query: `

Файлы:
- `embeddings.py` - класс обертка для получения E5 эмбеддингов с нужными префиксами.
- `create_index.py` - создание индекса базы FAISS.
- `check_search.py` - проверка качества индекса.

**Создание индекса:**

```
cd task3
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python create_index.py --src ../task2/kb --out ./vector_store
```
